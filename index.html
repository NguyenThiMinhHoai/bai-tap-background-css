Chào mừng đến với trang web của tôi

Đây là trang web được thiết kế bằng HTML và CSS. Trang web sử dụng màu nền và hình ảnh nền để tạo nên giao diện đẹp mắt, sinh động.

Khám phá thế giới lập trình

HTML giúp xây dựng cấu trúc trang web, CSS giúp thiết kế giao diện và JavaScript tạo ra các tính năng tương tác.

Hãy bắt đầu hành trình học lập trình ngay hôm nay!
